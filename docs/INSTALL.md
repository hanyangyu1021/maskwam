# Installation

## 1. Create an environment

```bash
git clone https://github.com/hanyangyu1021/maskwam.git
cd maskwam

conda create -n maskwam python=3.10 -y
conda activate maskwam
```

## 2. Install PyTorch

Install the PyTorch and torchvision builds matching the host CUDA version. For
example, follow the command generated by the
[official PyTorch selector](https://pytorch.org/get-started/locally/).

## 3. Install MaskWAM

```bash
pip install -r requirements.txt
pip install --no-build-isolation flash-attn
pip install -e . --no-deps
```

`flash-attn` is kept out of `requirements.txt` because it must be compiled
against the PyTorch/CUDA versions in the active environment.

## 4. Configure external assets

```bash
export MASKWAM_ROOT="$PWD"
export MASKWAM_DATA_ROOT=/path/to/data
export MASKWAM_PRETRAINED_ROOT=/path/to/pretrained_models
export MASKWAM_WAN_PATH=/path/to/Wan2.2-TI2V-5B
export MASKWAM_CHECKPOINT_ROOT=/path/to/checkpoints
export PYTHONPATH="$MASKWAM_ROOT:$PYTHONPATH"
```

Download the WAN2.2 base model, VAE, and T5 assets into that directory:

```bash
pip install -U huggingface_hub
hf download Wan-AI/Wan2.2-TI2V-5B \
  --local-dir "$MASKWAM_WAN_PATH"
```

For LIBERO, install the upstream repository and simulator dependencies, then
set:

```bash
export LIBERO_ROOT=/path/to/LIBERO
export PYTHONPATH="$LIBERO_ROOT:$PYTHONPATH"
```

MaskWAM fixes `mujoco==3.3.2` for compatible LIBERO rendering. Other MuJoCo
versions may change textures, colors, or segmentation output.

For MaskWAM-Seg, install SAM3 separately:

```bash
git clone https://github.com/facebookresearch/sam3.git third_party/sam3
pip install -e third_party/sam3
export MASKWAM_SAM3_ROOT="$PWD/third_party/sam3"
hf auth login
hf download facebook/sam3 --local-dir pretrained_models/sam3
```

The SAM3 repository and checkpoint are gated; accept their upstream license
before downloading.

## 5. Verify

```bash
python3 -c "import mask_wan_mot_real, mask_wan_mot_sim; print('imports OK')"
pytest -q
```

The unit tests do not require model checkpoints. Full inference requires
compatible CUDA, WAN/VAE/T5 assets, a MaskWAM checkpoint, and normalization
statistics.
